# v0.1 implementation programme

This directory decomposes the Foundation Baseline v0.2 into executable delivery work. `docs/IMPLEMENTATION_PACK.md` is the implementation source of truth; accepted ADRs remain normative.

## Delivery order
0. Repository contract
1. Executable modular kernel
2. Security and tenancy
3. Reliable application services
4. Foundational enterprise services
5. Reference product surface

Do not pull post-v0.1 capability products forward without an accepted scope change.
