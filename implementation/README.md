# v0.1 implementation programme

This directory decomposes the Foundation Baseline v0.2 into executable delivery work. `docs/IMPLEMENTATION_PACK.md` is the implementation source of truth; accepted ADRs remain normative.

## Delivery order
0. Repository contract
1. Executable modular kernel
2. Security and tenancy
3. Reliable application services
4. Foundational enterprise services
5. Reference product surface

All six phases are complete (0.1.x shipped). These files are retained as implementation history; post-v0.1 work is planned in `docs/POST_V0.1_ROADMAP.md` under ADR 40.

## v0.2 (in progress)

6. Identity application experience — `phase-6-identity-experience.md` (complete, 0.2.0-preview.1)
7. Audit experience, `.Api` projections, starters — `phase-7-audit-and-starters.md` (active)
8. Distributed capability, Stream B (planned)

A release spans several phases; v0.2 ships when 6–8 are complete. Do not pull post-v0.1 capability products forward without an accepted scope change.
